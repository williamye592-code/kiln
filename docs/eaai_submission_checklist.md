# EAAI Submission Checklist

## Framing

- [ ] The abstract clearly states the AI contribution.
- [ ] The abstract clearly states the engineering application.
- [ ] The paper is framed as an industrial early-warning framework, not only a CO forecasting model.
- [ ] The method forms a closed loop from industrial process mechanism to decision-level evaluation.

## Experiments

- [ ] Chronological train / validation / test split.
- [ ] Rule-based baselines.
- [ ] Machine-learning baselines.
- [ ] Deep temporal baselines.
- [ ] Graph and hypergraph ablations.
- [ ] Event-level warning metrics.
- [ ] Threshold sensitivity analysis.
- [ ] Case study visualization.
- [ ] Interpretability analysis.

## Reproducibility

- [ ] Code available.
- [ ] Configuration files available.
- [ ] Data dictionary available.
- [ ] Raw private data not uploaded.
- [ ] Random seeds recorded.
